Pengaturan Google Spreadsheet Sync

Hubungkan website dengan Google Apps Script agar setiap kali Anda klik tombol Simpan Progres Baca di web, datanya otomatis tersimpan langsung ke Google Spreadsheet Anda secara real-time.

Dapatkan URL ini dari menu Extensions > Apps Script > Deploy as Web App di Google Spreadsheet Anda.

📋 Cara Pasang Google Apps Script (Hanya 1 Menit):

  1. Buka Google Spreadsheet koleksi Anda.
  2. Pastikan kolom O (Status Baca), P (Volume Terakhir Dibaca), Q (Rating), dan R (Review Baca) sudah ada di baris judul (header).
  3. Klik menu Extensions > Apps Script.
  4. Buka file google-apps-script.js di folder project ini, copy seluruh kodenya, dan paste ke editor Apps Script.
  5. Klik tombol Deploy > New deployment, pilih Web App, atur Who has access ke Anyone, lalu klik Deploy.
  6. Salin (copy) Web App URL yang dihasilkan dan tempelkan ke kolom input di atas!
